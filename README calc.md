# Basic Calculator

A simple calculator built with HTML, CSS and vanilla JavaScript.

## Features

- Basic Calculations: Add, subtract, multiply, and divide numbers easily.
- Decimal Support: Perform calculations using decimal numbers, such as 2.5 + 3.7.
- Delete and Clear: Use the ⌫ button to remove the last digit and the AC button to clear the entire calculation.
- Multiple Operations: Solve expressions with more than one operator, such as "2 + 3 × 4", using the correct order of operations.
- Keyboard Support: Enter numbers and operators directly from your keyboard. Press Enter to get the result, Backspace to delete the last digit, or Esc to clear the calculator.
- Error Handling: Handles division by zero and displays an appropriate error instead of crashing.

## How to run
Download or clone this repo and open `index.html` in any browser. No installation needed.
